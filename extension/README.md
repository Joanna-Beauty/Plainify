# 白话本浏览器插件

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `extension/`。
4. 在项目根目录 `.env.local` 中配置 `DEEPSEEK_API_KEY`，运行 `npm run dev -- --port 5173`。
5. 打开白话本设置页，选择 DeepSeek 模型和网页悬停方式，再点击“同步术语与插件设置”。

插件兼容 Chrome 和 Edge。网页中选中文字后，原位置旁会出现“用大白话解释”按钮。点击后先预览大白话解释和生活化类比，选择“加入白话本”才会保存、高亮并同步到网站；选择“先不添加”不会写入术语库。

点击浏览器工具栏里的白话本图标，也可以手动输入术语。点击“生成解释”后只保存最新查询，不会直接收录；关闭再打开仍会显示该结果。用户确认“加入白话本”后才会入库，点击“清空”后才能查询新词。

网站设置页的“网页悬停显示”可以选择“大白话解释”“生活化类比”或“全部展示”。保存后，鼠标停在网页黄色高亮词上时会按该方式显示内容。

通过网页选词收录时会保存页面标题和完整 URL，手动键入则显示“手动输入”。右键菜单仍提供直接解释并收录的快捷方式。API Key 只由本机 `127.0.0.1:8787` 后端从 `.env.local` 读取，网页和扩展存储里不会保存 Key；升级时也会自动删除旧版本遗留的 Key、接口地址和服务商字段。

当前本地开发版会在 `127.0.0.1` 或 `localhost` 上识别白话本网页；正式部署时应把 `content.js` 中的可信应用域名换成实际域名。
