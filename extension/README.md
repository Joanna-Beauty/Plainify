# 加简大白话 · Plainify 浏览器插件

1. 首次使用先在项目根目录双击 Windows 的 `install-windows.cmd` 或 macOS 的 `install.command`，也可以运行 `npm run service:install` 安装本机常驻服务。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本目录 `extension/`。
5. 刷新加简大白话网站，确认首屏和设置页显示“插件已连接”。
6. 打开设置页添加模型服务，设置网页悬停方式并保存。术语和设置会自动同步。

扩展的网页访问权限用于读取用户主动选中的文字、显示解释入口和术语高亮。API Key 只由本机 `127.0.0.1:8787` 后端读取，不会保存到扩展。

更新旧版本时，请在扩展管理页只保留一个“加简大白话 · Plainify”，删除或关闭其他重复副本，再点击“重新加载”并刷新所有已经打开的普通网页。旧网页中已运行的内容脚本不会被新版本自动替换。

插件兼容 Chrome 和 Edge。网页中选中文字后，原位置旁会出现“用大白话解释”按钮。点击后先预览大白话解释和生活化类比，选择“加入术语库”才会保存、高亮并同步到网站；选择“先不添加”不会写入术语库。
生成中、网页悬停和插件底部状态会显示“提供方 · 具体模型”，以本机后端实际生效的模型为准；在网站保存或切换模型后自动更新。

点击浏览器工具栏里的加简大白话图标，也可以手动输入术语。点击“生成解释”后只保存最新查询，不会直接收录；关闭再打开仍会显示该结果。用户确认“加入术语库”后才会入库，点击“清空”后才能查询新词。

网站设置页的“网页悬停卡片”默认选择并优先展示“解释和类比”，也可以改为“大白话解释”或“生活化类比”。保存后，鼠标停在网页黄色高亮词上时会出现小灯泡并按该方式显示内容。点击黄色高亮可以固定解释栏；固定后可手动关闭，也可以直接归档术语。归档后解释栏立即关闭，当前网页中的同名黄色高亮同步消失。

在网站给已经熟悉的术语打钩后，术语会进入归档，并从首页、复习队列和网页黄色高亮中移除。归档页按归档时的分组展示术语，支持恢复和永久删除；原分组已删除时，恢复后的术语会回到“未分组”。

通过网页选词收录时会保存页面标题和完整 URL，手动键入则显示“手动输入”。右键菜单仍提供直接解释并收录的快捷方式。API Key 只由本机 `127.0.0.1:8787` 后端从 `.env.local` 读取，网页和扩展存储里不会保存 Key；升级时也会自动删除旧版本遗留的 Key、接口地址和服务商字段。

插件新收录的术语统一进入“未分组”。回到网站点击“整理未分组”后，系统只为新词选择已有大类或按需创建能容纳多个术语的新大类，不会修改已经归类的术语。

需要整体调整时，可在分组菜单中点击“重新整理全部术语”，阅读风险提示并确认后开始整理。系统会把术语收敛到最多 5 个宽泛大类，尽量保证每组至少有 3 个术语；应用预览后，未被新方案继续使用的旧分组会直接删除。

当前模型服务余额不足时，后端会显示明确状态并按递增间隔自动检查。充值到账后连接会自动恢复，不需要重启网站、后端或浏览器扩展；插件弹窗保持打开时也会自动刷新连接状态。

本机常驻服务会在 Windows 或 macOS 登录后自动启动，并在意外退出时自动拉起。可用 `npm run service:status` 检查运行状态；日志保存在项目的 `.logs/` 目录中。

当前本地开发版会在 `127.0.0.1` 或 `localhost` 上识别加简大白话网页；正式部署时应把 `content.js` 中的可信应用域名换成实际域名。
