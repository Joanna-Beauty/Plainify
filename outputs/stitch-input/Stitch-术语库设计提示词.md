## 提示词正文

请根据我上传的桌面端和移动端截图，优化“加简大白话 · Plainify｜你的个人术语库”的术语库页面。请把截图视为当前真实产品结构，而不是只参考配色的概念图。

### 产品与用户

这是一个本地运行的个人术语库。用户在阅读网页时遇到陌生的技术词、专业词或概念，可以收录到这里，由 AI 生成“大白话解释”和“生活化类比”，再进行查找、分组、归档和复习。

目标用户是希望降低理解门槛、逐渐掌握陌生概念的普通用户。页面的核心任务是让用户快速收录、查找、理解和整理术语。它是日常使用的知识工具，不是营销网站、内容社区或数据仪表盘。

### 必须延续的当前布局

请保留当前宏观信息架构，只优化比例、层级、密度、留白、字体、颜色和控件样式。不要重新发明页面结构。

桌面端：

1. 顶部为横跨全宽的固定品牌栏，高度约 64px，左侧展示 Logo、“加简大白话 · Plainify”和“你的个人术语库”。
2. 品牌栏下方左侧为固定侧栏，展开约 224px、收起约 68px。
3. 侧栏上部保留收起按钮和“术语库 / 快速复习 / 设置”导航。
4. 侧栏底部保留“在 B 站关注我”和插件连接状态。
5. 主内容顶部直接放置“粘贴术语 + 解释并收录”的输入区，不增加 Hero、欢迎语、统计数据或介绍模块。
6. 输入区下方是“最近收录”工具栏，包含术语数量、搜索、整理未分组、撤销整理和更多菜单。
7. 主体保持两栏：左侧是术语列表，右侧约 252px 是分组、归档和快速复习区域。
8. 术语列表保持扁平、适合连续阅读的列表结构，以分隔线组织内容，不要把每个术语改成厚重的悬浮卡片。

移动端：

1. 顶部固定品牌栏，左侧展示 Logo、产品名和“你的个人术语库”，右侧保留 B 站入口。
2. 隐藏桌面侧栏，底部固定“术语库 / 复习 / 设置”导航。
3. 收录输入框与“解释并收录”按钮纵向排列。
4. “最近收录”、搜索和整理操作纵向适配窄屏。
5. 术语内容保持单列阅读，分组、归档和复习入口放在术语列表之后。

可以微调区域比例、内部排列和控件位置，但必须保持上述页面骨架和使用顺序。

### 必须保留的元素和功能

不得增加、删除、合并或改变以下按钮与功能，也不要修改现有中文标签：

- 侧栏收起与展开
- 术语库、快速复习、设置
- B 站主页入口
- 插件连接状态
- 术语输入框和“解释并收录”
- 搜索术语或解释
- 整理未分组术语
- 撤销上一次整理
- 更多菜单中的“重新整理全部术语”
- 分组筛选和每组数量
- 管理分组
- 归档入口
- 开始快速复习
- 术语名称、来源、大白话解释、生活化类比和分组标签
- 将熟悉的术语归档
- 查看与编辑术语
- 等待解释时的“生成解释”和生成中状态
- 移动端底部导航

本次只调整视觉和布局，不设计设置页、复习页、浏览器插件或新的产品功能。

### 视觉方向

风格关键词：清晰、亲和、可信、轻盈、有秩序、适合长时间阅读。

请保留“黄色荧光标记”作为品牌记忆点，因为它来自阅读时标记陌生词的真实行为。黄色只用于关键操作、选中状态和小面积强调，避免大面积铺满。辅助色可以使用白色、深灰、低饱和绿色和克制的功能色。

品牌名称可以少量使用具有中文阅读感的字体；正文、按钮和辅助文字使用清晰的中文无衬线字体。字体必须是网页可落地的系统字体或免费字体。

请避免：

- 营销落地页和大型 Hero
- 新增统计看板、成就、趋势或推荐内容
- 米色纸张模板、深色科技控制台、蓝紫渐变
- 过度卡片化、卡片嵌套卡片和大面积阴影
- 超大标题、装饰性编号、渐变光球和无意义动画
- 过度可爱、儿童化或通用 SaaS 仪表盘风格

### 设计要求

1. 使用截图中的真实中文内容和真实术语，不使用 Lorem ipsum 或虚构英文占位内容。
2. 优先改善当前页面的信息层级、横向空间利用、工具栏拥挤和移动端阅读节奏。
3. 长术语、长解释、长类比和较长分组名称不能溢出或遮挡其他元素。
4. 所有图标使用统一的简洁线性风格，延续当前 Lucide 图标的视觉特征。
5. 控件需要有清晰的 hover、focus、disabled、loading 和 active 状态。
6. 桌面端和移动端都应保持紧凑但不拥挤，适合反复操作和快速扫描。
7. 只选择一个具有辨识度的视觉表达作为重点，其余部分保持安静和克制。

### 本轮输出

请基于相同的页面结构和功能生成两种有明显差异的视觉方案：

- 方案 A：更克制、更高效，重点优化排版、密度和空间关系。
- 方案 B：品牌感更强，但仍然是安静、实用的知识工具。

每种方案都输出：

1. 1280×720 桌面端术语库首屏。
2. 390×844 移动端术语库首屏。
3. 说明颜色、字体、间距、圆角、边框和页面栏位的核心规则。
4. 说明黄色荧光标记如何成为产品记忆点。
5. 不输出全新产品方案，不改变现有功能，只优化当前界面。
