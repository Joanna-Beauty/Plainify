# 加简大白话 · Plainify｜你的个人术语库

## 打开应用

网站地址：`http://127.0.0.1:5173/`

macOS 首次下载并解压项目后，双击根目录 `install.command`。脚本会检查 Node.js、安装依赖与本机常驻服务，并自动打开网站。也可以手动执行：

如果 macOS 提示无法验证开发者，请右键点击 `install.command`，选择“打开”并再次确认。

```bash
npm ci
npm run service:install
```

安装后会在 macOS 登录时自动启动，进程意外退出也会自动恢复。运行 `npm run service:status` 可以检查当前状态，不需要再手动执行 `npm run dev`。

首次打开网站会显示“三步上手”：先连接模型，再安装扩展，最后解释并收录第一个术语。暂时收起后仍可在首屏继续；全部完成后提示自动隐藏。

## 使用大模型

1. 打开网站“设置 → 模型”。
2. 点击“添加模型服务”，选择 DeepSeek、OpenAI、阿里云百炼、Moonshot AI 或智谱 AI。
3. 点击输入框旁的“获取 API Key”进入厂商官方控制台，然后填写 Key；如需代理或兼容接口，切换到“自定义地址”。
4. 点击“联通测试并获取模型”。测试只读取当前账号的模型目录，不发起对话生成。
5. 从返回的文本模型中选择型号，保存后第一个服务会自动设为当前使用。需要更换、切换或停用时编辑对应服务。

五个厂商的官方接口地址均已内置，自定义地址会优先用于模型发现、验证和正式调用。API Key 只保存在权限为 `0600` 的本机 `.env.local`，由绑定在 `127.0.0.1:8787` 的后端读取；网站和插件都拿不到完整 Key，也不会把它写进浏览器存储。不要把真实 Key 发到聊天、提交到 Git 或打进扩展压缩包。

## 安装浏览器插件

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目里的 `extension/` 目录。
5. 刷新加简大白话网站，确认首屏或设置页显示“插件已连接”。术语会自动同步，网页悬停偏好在保存通用设置后同步。

扩展需要网页访问权限，才能读取你主动选中的文字并显示术语高亮；API Key 不会进入扩展。

更新旧版本时，请在扩展管理页只保留一个“加简大白话 · Plainify”，删除或关闭其他重复副本，再点击“重新加载”并刷新所有已经打开的普通网页。旧网页中已运行的内容脚本不会被新版本自动替换。

安装后，在普通网页中选中文字，原位置旁会出现“用大白话解释”按钮。点击后先显示大白话解释和生活化类比，此时术语尚未保存：可以选择“先不添加”，也可以选择“加入术语库”。只有确认加入后，术语才会同步到网站并显示黄色高亮。

点击浏览器工具栏里的加简大白话图标，可以手动输入术语并点击“生成解释”。查询不会直接收录；最新查询在弹窗关闭后仍会保留，确认“加入术语库”后才会写入术语库。点击“清空”后可以查询新词。

在网站设置页的“网页悬停显示”中，可以选择只显示“大白话解释”、只显示“生活化类比”或“全部展示”。保存设置后，鼠标悬停在网页黄色高亮词上会按该方式显示。右键菜单仍保留直接解释并收录的快捷方式。插件调用大模型时由本机常驻服务提供后端能力。

## 整理分组

新收录的术语会先进入“未分组”。点击“整理未分组”时，DeepSeek 只处理这些新词：优先放进已有分组，确实没有合适分组时才创建新分组，已经归类的术语不会被移动。

点击分组标题右侧的管理按钮，可以新建、重命名、删除和合并分组。删除分组后，其中的术语会回到“未分组”；打开任意术语详情，可以从下拉列表中手动分配或变更分组。

自动整理不会直接改动数据，而会先显示变更预览，包括进入已有分组的词数、建议创建的新分组和每个术语的移动方向。确认应用后，如果结果不满意，可以点击工具栏里的撤销按钮恢复上一次整理。

工具栏右侧的更多菜单中保留“重新整理全部术语”。这个操作会使用宽泛、长期稳定的技术大类，最多生成 5 个分组，并尽量保证每组至少有 3 个术语。它可能改变已有术语的位置，同样会先展示预览；确认应用后，未被新方案继续使用的旧分组会删除，适合低频的全库重整。

## 数据位置

网页数据保存在浏览器 `localStorage`，扩展数据保存在 `chrome.storage.local`，API Key 单独保存在 `.env.local`。当前版本没有账号系统和云同步，更换浏览器或清理浏览器数据前需要自行备份术语。
