RAG来自 GitHub
大模型基础

先去你给的资料里找相关内容，再让大模型照着这些资料回答。这样它不是全凭“记忆”瞎猜，答案通常更靠谱。

像开卷考试：模型先翻资料，再组织答案。

Embedding来自网页插件
大模型基础

把一段文字变成一串数字，让电脑能比较两段话在“意思上”像不像，而不只是看它们用了哪些相同的字。

就像给每句话一个地图坐标，意思越接近，位置就越近。

Cherry-pick来自 Git
Git 与协作

从别的分支里只挑某一次提交拿过来，不用把那条分支上的所有改动一起合并。
