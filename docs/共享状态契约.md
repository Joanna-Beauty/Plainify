# 加简大白话 · Plainify 共享状态契约

更新时间：2026-08-29

## 目的

本文描述本地单用户版中术语、分组、复习、设置、浏览器扩展和本机后端之间的共享状态。
它用于约束后续功能梳理与实现，避免单个页面看似可用，但跨页面或跨端操作无法闭环。

本文先记录当前代码的真实行为，再列出需要收敛的目标规则。尚未确认的产品规则不得直接标记为已完成。

## 状态所有权

| 数据 | 当前事实来源 | 副本或缓存 | 持久化位置 | 说明 |
| --- | --- | --- | --- | --- |
| 术语库 | 网站 | 浏览器扩展 | 网站 `localStorage` 的 `baihuaben:terms:v1`；扩展 `chrome.storage.local.terms` | 网站打开后合并扩展新增数据，并向扩展下发完整术语列表 |
| 分组列表 | 网站 | 无 | `baihuaben:groups:v1` | 可以包含没有术语的手动分组；归档术语不计入分组统计 |
| 最近一次自动分组 | 网站 | 无 | `baihuaben:last-grouping:v1` | 只用于撤销最近一次自动分组 |
| 通用偏好 | 网站 | 浏览器扩展 | `baihuaben:settings:v1`；扩展 `chrome.storage.local.settings` | 网站保存后同步；扩展只消费网页悬停等必要字段 |
| 模型选择与模型目录 | 网站和本机后端 | 浏览器扩展保存调用所需的提供方与模型 | 网站 `baihuaben:settings:v1`；后端 `.env.local` | 后端配置决定凭据与实际可用性，网站配置用于发起具体调用和展示 |
| API Key 与自定义 API 地址 | 本机后端 | 无 | `.env.local`，权限 `0600` | 网站和扩展不得获得完整 Key |
| 模型连接状态 | 本机后端运行时 | 网站和扩展临时展示 | 不作为业务数据持久化 | 包含未配置、检查中、可用、可恢复故障和不可恢复故障 |
| 扩展解释预览 | 浏览器扩展 | 无 | `chrome.storage.local.popupPreview` | 只是尚未确认收录的草稿，不属于术语库 |
| 页面、抽屉、弹窗、加载和提示状态 | 当前页面 | 无 | 不持久化 | 关闭或刷新页面后可以丢失 |

### 所有权原则

1. 网站术语库是本地版的主资料库；扩展是离线收录入口和阅读侧副本。
2. 扩展可以在网站未打开时新增术语、补全空解释和归档术语；网站打开后负责合并并重新下发完整列表。
3. 分组、术语详情编辑、恢复、删除和复习结果由网站负责。
4. 本机后端是模型凭据、激活提供方和真实连接状态的唯一事实来源。
5. `selectedId`、`busy`、分组预览等界面状态不得被当作业务状态。

## 术语数据契约

| 字段 | 类型 | 含义与约束 |
| --- | --- | --- |
| `id` | string | 术语稳定标识；新建时生成，合并同名术语时优先保留网站已有 ID |
| `term` | string | 去除首尾空白并折叠连续空白；比较是否重复时忽略大小写 |
| `explanation` | string | 大白话解释；为空时术语处于待解释状态 |
| `analogy` | string | 生活化类比，可以为空 |
| `category` | string | 活跃术语当前分组；无有效分组时为“未分组” |
| `source` | string | 来源标题或“手动输入”等说明 |
| `sourceUrl` | string | 来源网页地址，可以为空 |
| `createdAt` | ISO datetime | 首次收录时间 |
| `updatedAt` | ISO datetime | 任一业务字段最后一次变化的时间 |
| `fieldUpdatedAt` | object | 内容、分组、复习和归档四类字段各自的最后更新时间，用于双端合并 |
| `status` | `pending` 或 `ready` | `explanation` 非空时为 `ready`，否则为 `pending` |
| `reviewCount` | number | 已提交复习判断的次数，初始值为 0 |
| `mastered` | boolean | 最近一次复习判断结果；归档和恢复不会修改该字段 |
| `lastReviewedAt` | ISO datetime | 最近一次提交复习判断的时间，可以为空 |
| `archived` | boolean | 是否退出活跃术语库、复习、分组统计和网页高亮 |
| `archivedAt` | ISO datetime | 最近一次归档时间；未归档时为空 |
| `archivedCategory` | string | 归档当时的分组；未归档时为空 |

### 基本不变量

1. 同一术语库中不应存在标准化名称相同的两个术语。
2. `status` 由解释内容决定，不应独立漂移。
3. 活跃术语使用 `category`；归档展示和恢复使用 `archivedCategory`。
4. 归档术语不进入首页、分组统计、自动分组、复习队列和网页高亮。
5. 删除术语表示从网站和扩展列表中移除；网站保留仅用于阻止旧副本复活的轻量墓碑。
6. 归档不是删除，解释、类比、来源、分组快照和复习记录均需保留。
7. 内容、分组、复习和归档分别按 `fieldUpdatedAt` 合并，不能用一个领域的修改时间覆盖另一领域的新数据。

## 术语生命周期

### 解释与收录

```text
未收录
  -> 解释预览（扩展临时状态，尚未入库）
  -> pending（已收录，但没有解释）
  -> ready（解释生成成功或手动补全）
```

- 网站手动收录：先写入术语库；自动解释失败时保留 `pending`。
- 扩展选词或弹窗：先生成预览，用户确认后才收录。
- 扩展右键入口：解释成功后直接收录；失败时仍以 `pending` 收录。
- 同名术语已存在时不新增副本，只允许补全缺失的解释、类比或来源。
- 旧数据时间相同时仍优先保留较完整内容；明确较新的内容修改可以保存主动清空的解释、类比或来源。

### 分组与归档

```text
活跃/未分组 <-> 活跃/已分组
      |              |
      +----> 已归档 <-+
                 |
                 +----> 恢复到原分组或未分组
                 +----> 永久删除
```

- 新收录术语统一进入“未分组”。
- 增量整理只处理未分组术语；全量整理可以替换活跃术语的全部分组。
- 归档记录当时的分组，但不改变 `mastered` 和复习记录。
- 恢复时原分组存在则恢复到原分组，否则回到“未分组”。
- 恢复后继续保留归档前的最近一次复习结果。

### 复习

进入复习页时从活跃术语中排序并固定最多 5 个术语，排序优先级为：未掌握优先，其次复习次数少的优先。
每次判断只更新源术语的 `mastered`、`reviewCount` 和 `lastReviewedAt`，不会改变本轮剩余顺序；点击“再来一轮”才根据最新结果生成新队列。

## 分组数据契约

1. `groups` 是用户可管理的分组目录，可以保存空分组。
2. “全部术语”和“未分组”是系统保留名称，不能创建、重命名或合并为普通分组。
3. 新建分组不移动术语；重命名和合并会同步更新活跃术语及相关归档分组快照。
4. 删除分组会让该组活跃术语回到“未分组”；已归档术语保留原快照，恢复时若分组不存在则进入“未分组”。
5. 增量自动整理保留现有分组目录；全量自动整理以应用后的活跃术语分组重建目录。
6. 撤销自动整理只恢复仍处于预期目标分组的术语，避免覆盖整理后的手动移动。

## 模型与设置状态契约

### 通用偏好

- `autoExplain`：网站收录时是否自动生成解释。
- `hoverExplanationMode`：扩展网页悬停展示解释、类比或两者；缺失或无效时默认展示解释和类比。
- 通用设置只有点击保存后才写入网站，并在扩展已连接时同步到扩展。

### 模型配置

- 网站保存 `provider`、`model` 和各提供方的可选模型目录，不保存 API Key 或自定义 API 地址。
- 后端保存各提供方的 API Key、自定义 API 地址、当前激活提供方和模型。
- 新增或更换凭据时，后端必须先使用候选配置验证，再原子替换 `.env.local`。
- 保存或切换模型时，选定模型必须存在于当前 API 地址返回的目录中，并通过一次真实生成验证；健康检查使用当前激活模型。
- 实际解释和自动分组请求显式携带网站当前选择的 `provider` 与 `model`；后端使用对应提供方的本机凭据。
- 设置页打开后以后端返回的激活提供方和模型刷新网站设置，并自动同步到已连接扩展。

## 网站与扩展同步

| 方向 | 触发 | 当前合并规则 |
| --- | --- | --- |
| 扩展 -> 网站 | 扩展就绪或扩展术语变化 | 优先按 ID、其次按标准化术语名合并；内容、分组、复习和归档分别比较更新时间；删除墓碑拦截旧副本 |
| 网站 -> 扩展 | 扩展连接后网站术语或设置变化 | 下发网站完整列表；按领域更新时间合并；网站列表之外的扩展术语被移除 |
| 网站 -> 扩展设置 | 保存设置 | 只同步提供方、模型、自动解释和悬停偏好，不同步密钥和自定义地址；不提供手动同步入口 |

同步必须继续满足：

1. 旧的活跃副本不能覆盖较新的归档状态。
2. 网站恢复后必须能把扩展中的归档副本恢复为活跃状态。
3. 网站删除后必须从扩展和网页高亮中移除。
4. 扩展新收录的解释、类比和来源不能被网站旧的空字段覆盖。
5. 同步期间不得把 API Key 或自定义 API 地址写入扩展存储、网页消息或日志。

## 跨模块影响

| 操作 | 术语库 | 分组 | 复习 | 扩展与网页 | 模型后端 |
| --- | --- | --- | --- | --- | --- |
| 收录术语 | 新增 `pending` 或 `ready` | 进入“未分组” | 后续可进入队列 | 同步后开始高亮 | 自动解释时调用 |
| 补全或编辑解释 | 更新内容和 `status` | 不变 | 卡片答案更新 | 同步后悬停内容更新 | 生成解释时调用 |
| 移动或整理分组 | 更新 `category` | 更新目录或撤销快照 | 卡片分组更新 | 同步术语副本 | AI 整理时调用 |
| 提交复习判断 | 更新复习字段 | 不变 | 推进当前轮次 | 同步术语副本，不影响高亮 | 不调用 |
| 归档 | 保存归档快照 | 从活跃统计排除 | 从队列排除 | 移除高亮和固定解释栏 | 不调用 |
| 恢复 | 回到原分组或未分组 | 重新计入统计 | 重新具备复习资格 | 恢复高亮 | 不调用 |
| 永久删除 | 移除记录 | 重新计算数量 | 移出队列 | 移除扩展副本和高亮 | 不调用 |
| 保存通用设置 | 不变 | 不变 | 不变 | 更新扩展偏好 | 不调用 |
| 保存模型配置 | 不变 | 不变 | 不变 | 同步提供方和模型 ID | 验证并持久化凭据 |

## 已收敛规则

1. `mastered` 只记录复习结果，归档与恢复不再修改它。
2. 单轮复习队列在进入页面时固定，评分不会引发本轮重排。
3. 双端按内容、分组、复习和归档四类更新时间合并，主动清空字段可以覆盖旧值。
4. 永久删除产生本地墓碑，旧扩展副本不能重新创建已删除术语；重新收录的新版本仍可进入术语库。
5. 设置页读取后端激活提供方和模型后，自动对齐网站及已连接扩展。
6. `npm run test:release` 已覆盖模型配置、归档、分组、复习、同步、服务恢复和核心闭环。
