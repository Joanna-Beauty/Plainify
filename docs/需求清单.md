# 加简大白话 · Plainify 需求清单

更新时间：2026-08-27

## 记录规则

- 一个需求只解决一个问题。
- 新想法默认先进入需求清单，不直接进入开发。
- 开发前需要确定优先级、依赖关系和验收标准。
- 状态分为：待讨论、已确定、待开发、开发中、已完成、暂不做。

## 产品路线

### 第一阶段：本地单用户版

当前版本优先满足个人本地使用：用户可以从 GitHub 下载项目，在自己的电脑上运行网站、后端和浏览器扩展。

- 不要求注册或登录账号。
- 术语与复习数据保存在本机。
- DeepSeek API Key 可以在前端设置页填写。
- 前端提交的 API Key 由本机后端写入受保护且不会提交到 Git 的配置文件。
- 浏览器扩展和网页通过本机后端调用 DeepSeek。

### 第二阶段：云账号版

产品成熟后增加账号体系和云端数据同步。

- 用户在不同电脑登录同一账号后看到同一份数据。
- 任意设备新增或修改数据后，其他设备自动获得更新。
- API Key 与账号绑定并安全保存在云端后端，不需要每台设备重复配置。
- 云端具体使用自建后端、Supabase，还是 iCloud/网盘方案，暂未确定。

## 术语归档

归档用于暂时退出学习流程，不等同于删除：术语内容、来源、分组和复习记录仍需保留，并且可以恢复到术语库。

| 编号 | 原子需求 | 状态 | 验收标准 |
| --- | --- | --- | --- |
| TERM-01 | 归档术语但不删除术语数据 | 已完成 | 归档后解释、类比、来源、分组和复习记录保持不变 |
| TERM-02 | 给熟悉的术语打钩即归档 | 已完成 | 点击术语卡片的勾选按钮后，术语进入归档并从首页消失 |
| TERM-03 | 归档状态保存在本机 | 已完成 | 刷新网站、重启浏览器或重启本机服务后归档状态不丢失 |
